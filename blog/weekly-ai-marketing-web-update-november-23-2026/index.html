Developments from November 16–22

This week delivered a particularly useful combination of developments: an urgent WordPress security update, a practical new way for marketers to build Google Workspace automations, more reusable AI skills, and an advertising feature that could improve performance during short promotions.

There's also a meaningful change in how organizations can control what their automated workflows are allowed to do.

The common thread is moving AI from individual productivity experiments into repeatable, governed business processes.

And unlike another announcement about a chatbot becoming 7% better at answering obscure riddles, these changes have reasonably obvious applications for people who build websites, manage campaigns, and produce marketing work for a living.

1. WordPress 7.1.5 fixes serious security vulnerabilities, including a potential remote-code-execution path

November 18 | Security release — immediate action recommended

WordPress released version 7.1.5, addressing multiple security vulnerabilities in WordPress core.

The fixes include an unauthenticated privilege-escalation vulnerability involving Template Part block attributes that could lead to remote code execution, SQL injection vulnerabilities, stored cross-site scripting, and unauthorized information disclosure through REST API endpoints.

Other fixes address multisite privilege escalation, the Interactivity API, XML-RPC, and Customizer functionality.

Two vulnerabilities were reported by Anthropic, providing another concrete example of AI-assisted security research contributing to open-source software maintenance.

Why it matters

This isn't simply another plugin security advisory.

Several vulnerabilities affect core functionality used by ordinary self-hosted WordPress websites. A site can have a well-maintained custom theme, updated ACF fields, and no questionable plugins while still being exposed through an outdated core installation.

The Template Part issue is particularly concerning because of the potential severity of the resulting compromise.

What to do

Confirm that maintained WordPress websites have been updated to 7.1.5 or received an appropriate security backport.

Pay particular attention to installations with disabled automatic updates, custom deployment pipelines, or hosting environments that control core updates.

After updating, verify critical functionality, including custom templates, Gutenberg blocks, ACF components, REST integrations, and frontend interactions.

The security fixes have also been incorporated into WordPress 7.2's release-candidate development.

2. Gemini in Google Apps Script becomes generally available, letting marketers build Workspace automations with natural language

November 16 announcement | General availability; phased rollout

Google announced general availability of the Gemini side panel in Apps Script following an earlier public beta.

Users can describe an automation in ordinary language and have Gemini generate the corresponding script.

The feature supports creating new scripts, editing existing code, adding triggers, and diagnosing runtime errors. Suggested changes can be reviewed and accepted or rejected in individual blocks rather than applied blindly.

It's accessible through the Apps Script editor, including from Google Sheets, Docs, and Slides. Availability covers eligible Business Standard, Business Plus, Enterprise Standard, Enterprise Plus, and certain AI add-on subscriptions.

Why it matters

This is one of the more immediately useful developments for marketing operations.

Consider the amount of repetitive work that happens inside Workspace: organizing spreadsheet data, generating formatted reports, moving information between documents, creating calendar events, and preparing recurring status updates.

Apps Script could already automate many of those tasks, but writing and maintaining JavaScript was a barrier for nondevelopers.

Gemini reduces that barrier while keeping the implementation inside Google's existing scripting environment.

That doesn't mean scripts are automatically safe or correct. They still execute with permissions, can modify data, and may interact with external services.

But it makes routine automation considerably more approachable.

What to try

Choose one repetitive reporting workflow, such as turning a structured Google Sheet into a formatted weekly Google Doc.

Have Gemini generate the script, review its proposed changes, and run it against test data.

Evaluate whether it produces the correct output, handles errors, and can be maintained without constant developer intervention.

Before enabling it with client information, verify OAuth permissions, external connections, and the organization's approved Workspace configuration.

Agency implication

This could help content, SEO, paid-media, and account-management employees automate tasks that previously required development assistance.

The opportunity isn't to turn everyone into a JavaScript engineer. It's to make simple operational automation available to more employees while preserving technical oversight for complex or sensitive workflows.

3. Gemini skills become shareable and can reference live Google Drive documents

November 16 announcement | Gradual rollout beginning November 12

Google expanded skills in the Gemini app with two particularly useful capabilities.

First, users can now share skills with colleagues, granting View or Edit access.

Second, skills can reference files from Google Drive, Gemini Notebook, and Google Photos, along with uploaded local files.

Drive files and notebooks remain connected to their current versions, meaning a skill can reference updated information without requiring users to repeatedly upload replacement documents.

Skills can be invoked directly or used automatically when relevant. Sharing and access management currently require the Gemini web app.

Why it matters

This is a meaningful development for teams trying to standardize how AI handles recurring assignments.

A content team could create a brand-voice skill referencing its current editorial guidelines.

An account manager could use a reporting skill grounded in an approved reporting template.

A design team could maintain a skill referencing visual standards and project documentation.

Unlike a prompt copied into a shared document, a centrally maintained skill can provide a more consistent starting point.

The live-document connection is especially useful because standards change.

There are also governance considerations. Skill sharing follows organizational Drive-sharing settings, and users need appropriate access to referenced Drive files.

What to try

Create one shared marketing-content skill grounded in an existing brand or editorial guidelines document.

Have two employees use it independently on comparable assignments.

Evaluate consistency, required editing, and whether updates to the source document are reflected appropriately.

Keep the initial pilot within approved Workspace information and permissions.

Agency implication

Reusable skills offer a practical way to encode specialist knowledge into workflows that more employees can execute.

For agencies, this could eventually become part of a standardized client onboarding and delivery system: approved voice, messaging, content structure, and review expectations available through reusable AI instructions.

4. Google adds Seasonality Adjustments to Demand Gen campaigns

November 18 | Newly available in Demand Gen

Google announced support for Seasonality Adjustments in Demand Gen campaigns using Target CPA or Target ROAS bidding.

The feature allows advertisers to tell Google's bidding systems when they expect a temporary increase in conversion rates, such as during a short promotion or limited-time sale.

The adjustment helps bidding respond to an anticipated conversion-rate change and then return to normal behavior after the promotional period.

Google also highlighted product feeds, creator partnerships, and shopping-oriented experiences within Demand Gen, but the new Seasonality Adjustments capability is the most directly actionable change in this announcement.

Why it matters

Automated bidding relies heavily on historical performance.

That can become a disadvantage during short promotions when customer behavior changes faster than the bidding system can infer from incoming data.

Seasonality Adjustments provide a way to communicate a known, temporary change in conversion likelihood.

This is particularly relevant to ecommerce advertisers running flash sales, limited-time offers, and other promotions with predictable conversion-rate effects.

However, the feature isn't intended for every ordinary seasonal fluctuation. Smart Bidding already accounts for many recurring patterns.

What to try

Identify a Demand Gen campaign associated with a short promotion and using Target CPA or Target ROAS.

Evaluate whether there is a defensible expected conversion-rate increase based on historical promotional performance.

If so, test a Seasonality Adjustment and compare results against the campaign's normal performance and business targets.

Don't invent an aggressive adjustment merely because the sale needs to perform better.

Agency implication

This adds another useful control for paid-media teams managing promotional calendars.

It reinforces the importance of aligning campaign management with merchandising, pricing, and actual business expectations rather than allowing automated bidding to operate without context.

5. Google Workspace Studio adds controls over what automated workflows can share and modify

November 19–20 | Phased rollout and expanded data-region support

Google introduced a new administrative setting called Collaboration steps for Workspace Studio.

Administrators can now distinguish between automations that perform private actions for their creators and those that interact with other people or shared organizational resources.

For example, an administrator could allow employees to create drafts and personal notifications while restricting flows that send messages to colleagues or modify shared files.

The setting is enabled by default, preserving existing behavior unless administrators change it.

Google also announced general availability of Workspace Studio Data Regions support, allowing eligible organizations to apply regional storage and processing policies to supported workflow infrastructure.

Some integrations and generative AI capabilities become unavailable when nonregional processing is disabled.

Why it matters

As employees build more automations, the question changes from Can this workflow run? to What is this workflow allowed to change?

An automation that formats a personal spreadsheet is very different from one that sends emails, updates shared documents, or modifies information used by an entire department.

These controls provide a more practical way to introduce automation without granting every workflow unrestricted collaborative capabilities.

The data-region changes are also important for organizations with stricter information-governance requirements, although feature eligibility and processing restrictions vary by plan.

What to try

Review whether Workspace Studio is enabled and which employees can create flows.

Identify workflows that communicate externally, modify shared resources, or handle sensitive information.

Determine whether Collaboration steps restrictions would be appropriate for particular organizational units or groups.

For organizations with regional-processing requirements, test the supported integrations before assuming every AI step will remain available under stricter settings.

6. WordPress 7.2 reaches release-candidate testing, with meaningful developer API refinements

November 17 | Release candidate; final release planned December 8

WordPress 7.2 reached its first release candidate on November 17.

Unlike last week's Beta 5 update, the release-candidate milestone signals that the project is entering its final stabilization period.

Recent fixes include improvements to the HTML and Interactivity APIs, script-module translations, plugin dependency messaging, client-side media uploads, and block-editor behavior.

The release also continues refining the Abilities API, which provides structured ways to expose WordPress functionality to other systems.

Other changes include responsive design controls, administration improvements, accessibility work, and updated bundled libraries.

WordPress 7.2 is still pre-release software and should not be installed on production websites.

Why it matters

For agencies moving toward custom WordPress themes and more agent-assisted development, the release-candidate stage is a useful opportunity to validate compatibility.

The Abilities API is particularly interesting for future automated WordPress operations because it offers a more structured interface for describing functionality.

But the immediate value is straightforward: identify breaking changes before the final release.

What to try

Test a representative custom-theme project against the release candidate in staging or WordPress Playground.

Focus on ACF integration, Gutenberg behavior, the Interactivity API, custom REST endpoints, responsive styling, and deployment workflows.

Document any regressions and update the project QA checklist before December 8.

Agency implication

Repeatable compatibility testing is increasingly valuable as development teams adopt coding agents and accelerate implementation.

The faster code gets produced, the more important it becomes to know whether that code continues working when the underlying platform changes.

Its November 18 Marketing Platform update highlights Google Audiences on Spotify in the United States and India, as well as Pinterest video and display inventory accessible through DV360. Relevant for larger programmatic advertisers, but not necessarily a priority for teams focused primarily on Google Ads Search, Performance Max, or smaller paid-media budgets.

The stronger immediate development story is applying reusable AI workflows to actual production and QA.

What we should actually do this week

  1. Confirm WordPress 7.1.5 deployment across maintained sites. This is the highest-priority action because the release addresses core security vulnerabilities, including potentially severe unauthenticated attacks.
  2. Pilot Gemini in Apps Script on one recurring marketing operation. Choose a low-risk reporting or document-generation workflow and measure the time saved, correctness, and maintenance requirements.
  3. Create a shared Gemini skill based on approved editorial or brand guidelines. Test consistency across employees and verify access permissions for connected Drive files.
  4. Review Demand Gen campaigns with upcoming short promotions. Evaluate whether Seasonality Adjustments would help communicate legitimate conversion-rate changes to Smart Bidding.
  5. Audit Workspace Studio collaboration permissions. Determine whether employees' automations should be able to send messages or modify shared resources, and apply restrictions where appropriate.
  6. Run WordPress 7.2 release-candidate compatibility testing. Focus on custom themes, ACF, Gutenberg, REST functionality, and deployment workflows before the planned December release.
  7. Test Nano Banana 2.1 in Google Pics. Compare targeted edits, text accuracy, and visual consistency against the current creative-production process.

The bigger pattern

This week's developments reinforce an increasingly important distinction between using AI tools and building AI-enabled operations.

Google is making automation easier to create through Apps Script and easier to standardize through shared skills. At the same time, Workspace Studio is adding controls that determine how far those automations can reach.

Google Ads is providing more ways for advertisers to communicate business context to automated bidding systems.

And WordPress continues evolving both its development APIs and its security requirements, increasing the importance of reliable testing and maintenance processes.

The most valuable opportunity for marketing and web teams is to make expertise reusable.

A content strategist's editorial standards can guide a shared skill. A developer's knowledge of WordPress architecture can inform automated QA. A paid-media specialist's understanding of promotional economics can shape bidding adjustments. An operations employee can automate routine reporting without needing to become a full-time programmer.

The advantage isn't that AI allows everyone to do everything equally well.

It's that more employees can execute useful work independently while specialist knowledge remains embedded in the process.

Because generating more work is easy.

Building an organization that can consistently deliver better work, with fewer bottlenecks and fewer expensive surprises, is where the real competitive advantage lives.
